TELEGRAM VIDEO MANAGER - CORREGIDO
==================================

IMPORTANTE:
Los tres archivos deben estar JUNTOS en la misma carpeta:

app.py
storage.py
telegram_core.py

No copies solamente app.py.

PASOS:
1. Descomprime este ZIP.
2. Abre la carpeta TelegramVideoManager_Fixed.
3. Ejecuta INSTALAR.bat.
4. Ejecuta INICIAR.bat.

Si prefieres PowerShell:

cd "RUTA\TelegramVideoManager_Fixed"

& "C:\Users\USUARIO DEL GOBIERNO\AppData\Local\Programs\Python\Python314\python.exe" -m pip install -r requirements.txt

& "C:\Users\USUARIO DEL GOBIERNO\AppData\Local\Programs\Python\Python314\python.exe" app.py

El programa creará automáticamente una carpeta data.

No compartas:
- API Hash
- códigos de Telegram
- contraseña 2FA
- archivos .session
